# Website Proposal for Wayne Radix

Interactive website proposal from [Savvy Tech](https://ghosten22.github.io/savvy-tech/) for Wayne Radix Taxi, Tours and Auto Rentals, Grenada.

## Files

- `index.html`: the proposal page
- `css/styles.css`: styling, including print styles for Save as PDF
- `js/main.js`: section menu, cost calculator, question panels and acceptance buttons
- `assets/`: Savvy Tech logo and the demo website screenshot
- `fonts/`: Geist and Instrument Serif, served locally so the page looks the same on every device
- `files/`: downloadable PDF and Word copies of the proposal
- `robots.txt`: asks search engines not to index the proposal
- `.nojekyll`: tells GitHub Pages to serve the files as they are

## Publish on GitHub Pages

1. In the `projects473` GitHub account, create a repository named `wjr-proposal`.
2. Upload everything in this folder to the root of the repository, including the hidden `.nojekyll` file.
3. Go to **Settings > Pages**, set Source to **Deploy from a branch**, choose `main` and `/ (root)`, then save.
4. After a minute or two the proposal is live at `https://projects473.github.io/wjr-proposal/`.

## Privacy

The page is set to `noindex`, so it will not appear in Google searches. Anyone with the link can still open it, so share the link with Wayne directly. Repositories on free GitHub accounts must be public for Pages to work.

## Updating the proposal

If prices or terms change, update `index.html` and replace the PDF and Word copies in `files/` so all three versions match.
